Benchmark grading and in-task checks are different

The benchmark grader tests the generated patch against the task’s expected outcome. In-task checks are the checks Rovara Code records and compares during the coding session.

This batch has separate grader evidence for all 50 tasks. Its in-task check records show 48 not verified and 2 verified. Both tasks with verified in-task checks were unresolved by the benchmark grader. A check can pass while the requested fix remains incomplete.

Five unresolved tasks contain an agent success claim. Their grader evidence still records failure. Inspect the saved output rather than treating that claim as the result.
