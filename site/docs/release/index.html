Published release#

PrepLabsAI/Rovara is public. The latest published release is npm @preplabsai/rovara-code v0.3.4 (MIT) and the v0.3.4 GitHub release, both published 13 October 2026. Earlier v0.3.0 artifacts retain their Apache 2.0 terms and grant.

v0.3.2 added the features pages mark Needs v0.3.2 or newer:

  • Quick and Full workflows started from Slack, with request routing and saved thread replies.
  • Plan decisions and comments on the task page.
  • Automatic checks, code and security reviews, and draft PRs; PR feedback proposals.
  • Sign in with ChatGPT.
  • Rovara loop on GitHub issues.
  • Workflow and Task People MCP tools (People changes default to off).

v0.3.4 (v0.3.3 was tagged but not published) fixes Rovara loop: the daemon keeps polling past errors, Claude Code and Codex sessions no longer get stuck on prompts or commits, and reviews see what collaborators asked for. See Rovara loop.

A deployment or CLI on v0.3.1 or earlier needs an upgrade for these. Task dependencies are not in a release. Install using Launch in AWS or the terminal →

Publication is separate from a fresh installation acceptance run. This website update did not deploy a new AWS environment.

Product name and existing commands#

The public product repository is PrepLabsAI/Rovara; this website uses the approved display name Rovara Code. Package @preplabsai/rovara-code installs both rovara and the compatible agentx command. Configuration paths, AWS resources and MCP identifiers keep their existing identities.

Current licence#

PrepLabsAI grants the MIT License for all PrepLabsAI-owned Rovara code, including earlier releases. PrepLabsAI's previously issued Apache 2.0 grant also remains available for its owned code. Third-party components retain their own licenses.

Read the MIT License, the retained Apache License 2.0, and the license grant notice.

Runtime requirements#

The published CLI declares Node 22.19.0 or newer; Node 22 LTS is recommended. Launch in AWS does not need Node on your computer. The current install region is us-east-1.

The MCP reference matches that commit’s tool definitions. See the source claim record and the workflow source record.

Earlier preview pages were checked against native-workflow branch 3455a367005972659875667b82d7b5d28a2da727, since merged and released in v0.3.2. Historical benchmarks retain their own dates and candidates. A website build does not prove a live installation.
